# respi-monitor

Interfaz web para visualizar la señal respiratoria en tiempo real recibida desde el servidor WebSocket del proyecto principal.

## Scripts disponibles

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Uso

1. Asegúrate de tener el servidor WebSocket corriendo desde la raíz del proyecto.
2. Inicia la interfaz web con npm run dev.
3. Abre http://localhost:3000.

## Tecnologías

- Next.js
- React
- TypeScript

## Notas

- La lógica de conexión y la experiencia visual se mantienen intactas.
- Este directorio está preparado para trabajar junto con el servidor principal de WatchAir.
